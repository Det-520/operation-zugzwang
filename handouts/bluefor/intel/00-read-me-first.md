# BLUEFOR Intelligence Products: Read Me First

**BLUEFOR EYES ONLY.** **Never show these to REDFOR.** *Fictional training scenario.*

## Rules for using them

- **Nothing here is an established fact.** A Pro or Con that relies on a report counts only as far as the report is believable. Confirm what matters with an RFI or an ISR COA before you bet a turn on it (Rules Handbook §2.3).
- **Ratings.** Official reports carry an analyst's rating in the NATO "Admiralty" format: a letter for the **source** and a number for the **information**. The rating is an analyst's judgment, not the truth. Analysts can be wrong too.

| Source reliability | | Information credibility | |
| --- | --- | --- | --- |
| **A** | Completely reliable | **1** | Confirmed by other sources |
| **B** | Usually reliable | **2** | Probably true |
| **C** | Fairly reliable | **3** | Possibly true |
| **D** | Not usually reliable | **4** | Doubtful |
| **E** | Unreliable | **5** | Improbable |
| **F** | Reliability cannot be judged | **6** | Truth cannot be judged |

- **Dates** are relative to D-Day. Phase I takes place at D−3. Times are local.

## How to read the formats

- **Source reports** pass on what a human source said. They are raw reporting, not finished intelligence. Read the source description and the comments before the text.
- **Asotin reports** are what Asotin chose to share with you. Asotin has its own interests.
- **Assessments and comments** use standard estimative words. They describe the analyst's judgment of likelihood, not certainty.

| Word | Roughly means |
| --- | --- |
| almost certainly | 95% or more |
| very likely | 80–95% |
| likely, probably | 55–80% |
| roughly even chance | 45–55% |
| unlikely, probably not | 20–45% |
| very unlikely | 5–20% |
| almost no chance | under 5% |

*Confidence* (low, moderate, high) is separate. It describes how good the evidence is, not how likely the event is.

- **Open sources** (news, social media, foreign statements) are reproduced as collected. Nobody has checked them.
