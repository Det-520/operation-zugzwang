**WHITE CELL ONLY.** The lead adjudicator keeps this checklist at the table and ticks it off. The *how* is in the White Cell Handbook; each line names the section. Clock times assume the 1345 start (Handbook §3). If the start moves, the timer program keeps the durations.

## 1. Before the LLAB

### One week out

- [ ] The ASAP release has gone to every player: Player Rules Handbook and Player Forms (Handbook §2.1).
- [ ] Release the scenario over Canvas: Scenario Brief, Scenario Schedule, Starting Conditions, and the map.
- [ ] Each table has a lead adjudicator, a REDFOR logger, and a BLUEFOR logger (Handbook §1). Each team has a GMC evaluator.
- [ ] A white cell run-through is on the calendar.

### 24 hours out

- [ ] Teams and both flight commanders for each team (Phases I–II and III–IV) are assigned.
- [ ] Email each team **only its own** release: REDFOR gets the REDFOR folder, BLUEFOR the BLUEFOR folder. **Nobody gets the other team's documents.**
- [ ] Every white cell member has read **both** sides' intelligence products and the key (Intelligence and Injects §3).
- [ ] Every white cell member has read the ground truth (Intelligence and Injects §1), the RFF pools (Handbook §7), and the scoring tables (Handbook §8).
- [ ] The timer and dice program (`whitecell-clock.html`) opens on each lead adjudicator's laptop, works offline, and can be shown on a screen.
- [ ] One Print Packet printed for each table (4) (the full packet, or the Reference Forms version plus photocopies), game pieces in colour, forms in greyscale. Spares kept with the white cell. Counters and cue cards cut. Hidden counters in an envelope.
- [ ] Each table agrees with the others on what counts as an auto-success, so the four games are scored alike (Handbook §5.1).

## 2. Table setup (before 1345)

- [ ] Table arranged so both teams and the white cell sit in a circle (LLAB-SETUP §5).
- [ ] Map down, with the track board beside it where both teams can see it.
- [ ] Track markers at the start: Strait **Open**, Opinion **−1**, Will **3**, Stability **4** (Handbook §2.3).
- [ ] Starting-condition cue cards face up beside the map: S-R1 to S-R4, S-B1 to S-B5.
- [ ] **Visible** counters placed by zone (Handbook §2.3). **Hidden** counters stay in the envelope.
- [ ] Each logger has its side's placement form face down (White Cell Forms §4). The objective status card is face down with a logger (White Cell Forms §3).
- [ ] Each team has its stack of player forms: OPORD format, COA and Cons worksheets, request slips, secret COA slips.
- [ ] Timer program open, on screen, on the Phase I block. Phase I opening script ready (Handbook §3.1).

## 3. Phase I: Planning (1345–1403)

- [ ] **1345** Read the Phase I opening script. Start the 18-minute timer.
- [ ] **1357** Read the minute-12 call. Collect up to **4** request slips per team. Refuse extras.
- [ ] **1357–1403** Lead adjudicator writes the RFI answers and RFF rulings. Phase I RFFs count from Turn 1 (Handbook §7).
- [ ] **1400–1403** Each logger hears its team's oral OPORD brief and writes its **planned COAs** (up to 3, Turns 1–3) on the placement form.
- [ ] BLUEFOR logger writes the zone BLUEFOR chooses for each NASAMS battery (**B-06a, B-06b, B-06c**).

## 4. Kickoff inject (1403–1405)

- [ ] Read the kickoff inject (Intelligence and Injects §4.1).
- [ ] Move Strait Traffic to **Restricted**.
- [ ] Hand back the Phase I RFI answers and RFF rulings, with arrival turns.

## 5. Every turn (Turns 1–7)

Tick each box as you go. Turns 1–4 are Phase II (1405–1505); Turns 5–7 are Phase IV (1520–1605). Running behind? Shorten **Prepare**, never the Cons (Handbook §4.2).

## 6. Debrief 1 and handover (1505–1512)

- [ ] Phase I–II flight commanders lead Debrief 1.
- [ ] Command passes to the **Phase III–IV flight commanders**.

## 7. Phase III: Planning and FRAGO (1512–1520)

- [ ] **1512** Start the Phase III timer. Teams plan Phase IV under the new flight commander.
- [ ] **1519** Read the Phase III call (Handbook §3.1).
- [ ] **1519–1520** Each logger hears the 1-minute oral FRAGO and writes **up to 2** new planned COAs for Turns 5–7 on the placement form.

## 8. Phase IV: Turns 5–7 (1520–1605)

- [ ] Run Turns 5–7 with the grid in §5.

## 9. End of game and Debrief 2 (1605–1612)

- [ ] **1605** Read the end-of-game script (Handbook §3.1).
- [ ] State the end state: all four tracks, who holds Omak's coast, any Cosmopolis ground forces on Omak soil, any Asotin personnel in Omak, any agreements (Handbook §8).
- [ ] Score R1–R3 and B1–B3 as Achieved, Partial, or Not achieved. Check R3 against the scoring notes.
- [ ] Fill in the score sheet (White Cell Forms §1).
- [ ] Phase III–IV flight commanders lead Debrief 2.

## 10. Cleanup

- [ ] Collect the hidden counters, the placement forms, the objective status card, and every request and secret COA slip.
- [ ] Collect the intelligence products and team documents left on the table. Don't leave either side's secrets in the room.
- [ ] Give the score sheet to C/Nacanaynay.
- [ ] Put the room back the way you found it.
